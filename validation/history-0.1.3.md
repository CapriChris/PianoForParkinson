# 0.1.3 历史分页与组趋势验证

日期：2026-10-14。Medium Phone / emulator-5554 / API 37。使用独立随机 no-backup 数据库，用户连接的物理手机未安装或清除数据。

## 功能与数据边界

历史以开始时间降序、会话 ID 升序，每次读取 21 条判断是否还有下一页，只显示 20 条。分页使用最后一条的时间／ID，不依赖 OFFSET；同时间记录也有稳定顺序。刷新和销毁令旧请求失效；加载更多失败保留已加载记录，重试复用游标。SESSION 摘要按会话原指标版本关联，避免多个指标版本重复显示一条会话。

趋势按现有 comparison_key 查询自然 COMPLETED 组，与 BLOCK 摘要、会话指标版本和组比较键一致才进入图表。最近 20 组按 ended_utc_ms、block_id 确定排序，显示日期使用记录时的 UTC 偏移。横轴等距展示排序后的组，纵轴为主要正确率 0～100%，不表示等长真实时间间隔。1～2 组只有点，3 组及以上连线。每组显示封存分子／分母，选择条目高亮点；没有重算旧分数。

当前趋势仅包含 G1 完整正确序列比例及 S1 首次正确音符比例，尚未提供其他时序／辅助指标的趋势切换。组未自然完成、比较键为 null、未知声音条件均排除；条件选择包含已存条件，不同键不混画。

Android API 33 以上以 SoundPool 的 AudioAttributes 调用 [getAudioDevicesForAttributes](https://developer.android.com/reference/android/media/AudioManager#getAudioDevicesForAttributes(android.media.AudioAttributes))。仅单一且可识别输出归入 BUILT_IN／WIRED／BLUETOOTH；未知、多路或查询失败返回 UNKNOWN。它查询预期媒体路由，不证明物理发声、用户听到声音或延迟达标。API 24～32 保留已有耳机检测，内置输出仍可能 UNKNOWN。本轮实际路由验证只覆盖模拟器内置输出；蓝牙、有线、USB 和较旧系统运行矩阵未验证。

## 验证结果

| 验证 | 结果 |
| --- | --- |
| 静态分析 | 无问题 |
| 单元／内容／布局 | 共 75 个独立用例通过：原 56 + 3 个摘要读取／时区用例 + 8 个图表布局 + 8 个全页面／选择条件布局 |
| 历史 SQLite／控制器 | 45 条记录、相同开始时间、跨页删除、分页期间新增、异指标版本摘要、数据库关闭后读取失败／重试、刷新与分页并发通过 |
| 趋势 SQLite | 24 个同条件完整组只取最近 20；等级／模式／暂停／声音条件隔离；UNKNOWN 和局部组不进入；删除及清除级联；读取不改变摘要；外键检查通过 |
| 实际页面 | 空记录、2 组只画点、3 组连线、选择条件、读取失败和重试通过 |
| 路由 | API 37 原生能力报告为 BUILT_IN，有声条件组可以查询；UNKNOWN 组继续排除 |
| 暂停／返回回归 | 真实 MonotonicClock＋SoundPool，首个有效结果保存、同 attempt 继续不重播、状态栏隐藏恢复、注入保存失败后左上角返回和首页重试通过 |

布局覆盖真实应用主题：360×640、800×360，简体中文／英文，字号比例 1.0／2.0。首次补充布局检查曾失败：实时模拟器测试中强行修改测试视图尺寸后的滚动查找失败，布局矩阵改用 widget 测试；横屏大字号的点击检查还需等滚动后的布局帧完成。最终 8 组页面／选择测试全部通过；其他用例在全套运行通过，未把重复执行算作新用例。

本轮重新运行的 Android 独立用例为新增 3 项及已有真实声音流程 1 项。原生契约、完整 G1／S1 两组流程及 3 项保存压力用例的上一版验证保留，没有宣称本轮重新跑过所有 9 项。新增查询测试使用虚拟输入、确定性时间及真实 Android SQLite，不替代物理设备练习、临床判断或音频测量。
