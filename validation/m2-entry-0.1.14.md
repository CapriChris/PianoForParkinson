# 琴伴 0.1.14：M2 竖屏入口

日期：2026-10-17。内部演示，开发密钥签名。

## 行为

竖屏和横屏列表均显示“双区配合”。点击后请求横屏，在模式内部进行双触点检查；通过后直接进入说明。列表不再以独立检查按钮替代模式卡片。上次内容重练与结果页重练也经过相同流程。

左右区域与底部继续按钮固定显示，说明独立滚动，避免滚动手势拦截第二个触点。左右触点与原生双触点确认同时满足、宽度至少 600 dp 且无读屏才可继续。检查不创建会话或成绩；正式开始前的原生能力检查仍保留。见 [设计修订](../../设计修订/2026-10-17-M2竖屏入口与进入后检查.md)。
