# 0.1.5 节奏、时值与音量验证

日期：2026-10-15。Medium Phone / emulator-5554 / API 37，延续前次临时 software GPU 的模拟器实例。本轮不证明默认 GPU、最低 API 24 或物理音频延迟。用户报告已完成 0.1.4 真机验证，0.1.5 尚未由用户报告真机结果。

## 规则及界面

- S2 锁定八音短句计划，BPM 40／45／50／55 使用有理节拍的整数计算。完整示范、倒数、首目标一秒延迟；响应窗口 [target−400ms,target+400ms)，每窗有效 800,000 μs。
- 首错后补对仍错键，正确后额外行为不成为纯命中；空白、禁用、重叠及窗口外响应保留。提前／延后仅由 HIT 产生误差，摘要绝对误差不混入漏按。窗口外事件没有 trial／attempt 归属，不分给附近目标。
- 按住不推迟下一节拍；同一琴键连续目标不会继承上一次按住时值。USER 暂停冻结窗口、节拍原点和视觉按住计时，继续同一 attempt 不重播。技术重试显式重新锚定剩余计划；晚帧失效、手动降低 BPM、完整组和自适应快照均覆盖。
- G1／S1／S2 示范与 S1／S2 操作时值条；G1 作答不要求按住长度。S1／S2 时值仅作提示，未增加时值得分条件。固定 24 dp 提示行与键宽对齐，不改变琴键命中区域。
- 8 组 S2 页面用例覆盖 640×360／800×360、中／英、文字比例 1.0／2.0，验证时值条、键盘位置、同屏暂停和结果。4 组独立音量页用例覆盖 360×640、双语和双倍字号；卡片内边距与分隔保留，支持滚动查看。
- 设置两项 0～100% 音量可各自保存与试听；默认琴键 85%、语音 100%，不修改媒体系统音量。旧 JSON 补字段和默认值仅发生一次，静音和显式音量保留，坏范围拒绝写入；排队保存不覆盖另一项。

本轮通过 6 个独立 Android 集成用例，均使用随机命名的隔离数据库并清理，不使用正常练习库：

5. 既有 G1／S1 真实时钟／声音回归：首个动作落库、暂停继续不重播、注入保存失败仍可返回并重试、状态栏恢复。
6. 既有 G2／G3 真实时钟／声音回归：完整窗口、同一目标和 attempt 暂停、首有效结果落库、返回保存。

本轮可用 Android 集成用例共 17 个，其他旧原生契约、完整 G1／S1／G2／G3 两组、历史和压力套件没有全部重跑，保留版本化报告。单元测试与 Android 流程中的断言不单独累计成新用例。

测试脚本初次假定列表所有卡片已实例化、指标标签为独立 Text，修正为可见列表项及 MetricTiming 标签定位。Android 测试最初读取了尚在恢复动画中的状态栏，并有一次测试清理重复 dispose；修正等待原生状态和一次清理后，两项最终串行复测通过。曾中止一次尚未修正状态栏等待的重复运行，不计为通过。没有将这些失败运行累计为新用例。
