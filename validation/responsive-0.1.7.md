# 0.1.7 倒计时、短按反馈与拍点同步验证

日期：2026-10-15。Medium Phone / emulator-5554 / API 37，沿用此前临时 software GPU 实例。新版仍需用户真机回归，不以模拟器证明物理音频延迟或默认 GPU 稳定性。保留用户其他文字调整，包括首页的“琴伴”和简化后的说明。

## 规则及界面

- G1／G2／G3 作答倒计时使用原时间预算，暂停冻结；G1 每个序列位置重新获得原有预算，超时即封存当前项。沙漏、数字和细进度线组成浅绿卡片，固定键盘区域不移动。
- G1／S1 短按反馈保留到下次有效琴键输入；G1 到期也清除。G2／G3 短按后所有琴键灰显并锁定到窗口结束，随后清除，不残留到下一项。
- G2 GO／G3 满时值后立即结束当前项，清除目标高光和时值条；下一提示仍遵守原项间隔和全部触点释放条件。NO_GO 保留完整等待窗口，误按也显示真实按住进度。
- G1 重看演示不打开答案提示，增加帮助重播后提供文字与当前目标键高亮。G3 禁用重播，G2／S1／S2 禁用增加帮助。S1 目标高亮与时值条同时出现，暂停一起隐藏。
- S2 演示加入节拍器和整句进度；当前音符在计划拍点切换，不跟随提前开启的响应窗口。指针在拍点经过正中。45／50／55 BPM 分数微秒按整数计划边界同步，不累计漂移。删去“准备／现在弹奏”。

配置 `demo-cognitive-2.1.0`，任务／规则／指标／自适应 2.1.0，`interaction_policy=RESPONSIVE_HOLD_V1`。G2／G3 实际有效时长可以小于窗口上限；所有结束时间与暂停时长仍逐项验证。数据库 schema 1，不修改旧封存成绩。旧 0.1.5／0.1.6 配置 fixture 独立回归，新配置的难度与趋势条件独立。
