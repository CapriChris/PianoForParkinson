# 琴伴 0.1.13 验证

日期：2026-10-17。内部演示，开发密钥签名；未进行本轮物理设备验收。

## 修复与新增

- 七种练习说明及其他语音组件离开页面、被覆盖、后台时停止；原生以 speech_epoch 拒绝迟到的旧朗读，恢复前台不自动播放。
- T3 横屏四拍固定同排，高亮／全程进度同钟；参考节奏练习压缩节拍区，上行节拍器和速度、下行四拍。上下顺序为说明、节拍区、同排操作按钮、琴键。第一教学页无琴键；隐藏状态栏移除标题上方空行，退出恢复。普通字号中英文 914×411（包含 24 dp 底部安全区）三页静止与示范均无需滚动；800×360 保证按钮无需滚动可见，并保留最多 56 dp 滚动空间以容纳至少 96 dp 的琴键。大字号保留滚动。
- M2 双区配合完成判定、六键提示、设备双触点检查、窗口／容差、结果指标、历史、组趋势、自适应和持久化校验。任务版本 2.2.0，schema 仍为 1。

规则见 [设计修订](../../设计修订/2026-10-17-语音生命周期与M2双区配合.md)。下一功能任务为同条件趋势增加指标切换。

## 停帧专项：保留未通过项

默认 Impeller OpenGLES 下，M1 示范持续保存专项复现帧编号 556 不再增长，保存任务为空且无存储错误；采集后停止独立测试包，记录为未完成／失败。**不把此项计为通过，也不宣称停止出帧已修好。**

同一用例仅添加 `--no-enable-impeller` 的 Skia 对照完整通过（28 秒、442 示范帧、9 次保存）。一次对照指向渲染／Vsync 链路，仍不足以确定具体原生调用栈或保证其他运行永不复现。正式包渲染策略未改。原模拟器配置、驱动与快照未改。详见 [完整分析与原始证据](emulator-analysis-2026-10-17.md)。
