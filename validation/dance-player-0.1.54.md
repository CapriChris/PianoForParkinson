# 0.1.54 舞蹈播放器与安装包体积（2026-11-01）

版本0.1.54+55，pubspec和运行时版本常量同步更新。本轮实现：

- 普通训练窗口按视频比例计算高度，移除240dp最小高度；视频使用覆盖填充消除额外黑区。全屏画面比例与屏幕不一致时裁切边缘，不拉伸视频。
- 音量图标正上方出现竖向滑条，水平中心与图标一致。弹层跟随可用高度调整，主题使用琴伴的暖白内容面、深绿滑条、边框和圆角。
- 当前倍率在音量左侧显示为0.75x／1.0x／1.25x；点击弹出三档选项，采用共享主题颜色、圆角和勾选标记。删除更多三点图标及后退10秒功能。
- 全屏左上角返回始终可见，可返回普通训练布局。
- 退出弹窗用同一行的左右等宽按钮，左“继续练习”、右“退出”，放大字号允许按钮内部换行。
- 拖动开始记录之前的播放状态并暂停；拖动过程中保持暂停，结束后才seek和恢复先前状态。原本暂停的会话继续暂停。后台、会话或部分切换会取消旧的自动恢复，避免迟到回调播放新会话；拖至结尾不自动从头重播。

## 间距

`lib/features/dance_player_page.dart`：

```dart
const danceControlsProgressGap = 4.0;
const danceProgressTouchHeight = 32.0;
```

前者是控件行与进度条触控区域之间的逻辑像素间距，增大则距离变大。进度轨道在后者定义的触控区域中居中，因此后者也影响到轨道中心的距离。通常只改前者即可。

## 包体积

当前随包加载的是三段中文MP4和一段英文WebM，pubspec显式列出四个文件。中文209.8MiB、英文328.5MiB，视频合计538.3MiB；通用包中的native库约62.9MiB，其他音频／图像等资产约26.0MiB，其余约1.2MiB。视频占通用包约86%。因此架构精简只改善约41.7MiB，无法替代视频资源优化。

可选后续方案：

1. 按需下载并缓存课程：代码／界面／必要音频在首包中，用户选择课程后下载，校验并原子提交缓存，支持下载进度、重试、离线播放和删除缓存。需准备稳定的获授权视频地址、资源版本与缓存管理；本轮未改为联网资源。
2. 转码视频：评估720p、合适码率及编码格式，检查动作、文字、音画同步和低端设备兼容后再替换生成的播放副本；原始文件保留。未声称已完成或保证压缩比例。
3. 按语言拆课程资源／单架构或AAB分发：前者需设计切换语言后的下载流程；后者可减少代码库下载，但不会自动让当前Flutter assets中的英文视频消失。
