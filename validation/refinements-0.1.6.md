# 0.1.6 全模式时值、真实琴音与节拍验证

日期：2026-10-15。设备：Medium Phone / emulator-5554 / API 37，沿用此前临时 software GPU 实例。用户已反馈 0.1.5 真机问题，本轮新版仍需真机回归；不以模拟器证明主观音质、物理音频延迟或默认 GPU 稳定性。

## 功能及兼容

- 统一引导和设置的语言按钮，选中项有浅绿背景、粗边框与勾选。预览按宽度使用三／五键，已解释原因；正式训练布局独立。
- 设置删除声音／语音开关，保留独立音量、百分比和试听。旧静音转换为对应音量 0%，滑杆恢复音量不会被隐藏开关挡住。
- 用户已确认全部正式任务要求 400 ms：G1／S1 短按保留当前音重试；G2／G3／S2 记录 TOO_SHORT 后继续原计划；NO_GO 不按键。G1／G3 不通过预置目标时值条泄露答案。暂停冻结活动计时；继续不重播。
- S2 四拍预备、持续节拍器、摆锤、拍点、整句八音时间轴与连续进度。正确但稍晚的 DOWN 可使用时值尾段，最迟在下一匹配窗口前结束，不移动下一节拍。
- 七个琴键改为 Alexander Holm 的 Salamander Grand Piano V3 实录采样，固定上游 revision 与文件哈希，CC BY 3.0 完整许可、署名与修改说明随包提供。原生松键 80 ms 释放。
- 当前配置、指标与规则为 2.0.0；旧版精确配置 fixture 单独回归，封存成绩不改写。SQLite schema 仍为 1，不进行表迁移；新参数配置的难度档案独立。
