# 琴伴 0.1.17 开发与构建记录

日期：2026-10-18（北京时间）。版本：0.1.17+18。

## 实现范围

本轮推进近期开发与修复第 1～7 项，开发改动如下：

1. 配置／环境／布局／输入／历史摘要检查，新输入 NFC，冻结字段字典；设置与启动错误页可进入只读、分批记录审计，坏历史记录保留并提示。
2. 模拟器 Skia 兼容策略、前台无帧技术暂停与原生双语提示；训练刷新隔离，保留真实提示呈现锚点。停帧效果与根因仍待验证。
3. schema 1→2 推荐索引迁移，升级前 checkpoint、关闭并复制原库，副本独立日志格式和只读校验；事务失败保留原库与备份，未知版本拒绝写入。
4. 所有模式后台快照，保存请求合并，一个会话的写入缓存；资源上限触发保存完成部分并结束，不丢弃已记录事件、不自动删除旧记录。
5. 近七个当地日认知任务轮换、最近使用歌曲推荐，推荐读取失败仍可自由选择。
6. 三段原创八音曲库及选曲，说明展示曲名，再练与继续上次内容恢复同曲，旧曲目与封存数据不重写。
7. 主动降难度入口、装饰动画与系统减少动画、关于页同步；活动／未保存会话不能直接清除记录。
