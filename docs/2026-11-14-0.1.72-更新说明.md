# 琴伴 0.1.72（构建 73）更新说明

日期：2026-11-14。基于上一公开版本0.1.70，包含本机0.1.71的提醒修复和后续界面优化，发布标签 `v0.1.72`。

## 本次更新

- 修复通知图标被 Android release 资源缩减移除、导致计划页显示“无法读取提醒权限”的问题。
- 统一“提醒设置”：进入后检查并申请通知和准时提醒；自启动、允许后台活动分别提供“去开启”，从系统页返回自动复查。提供常见品牌入口与标准页面回退，不再自动串行打开厂商设置。
- 通知显示提供系统设置入口；跳转传入本应用包名和定位/高亮参数。熄屏、锁屏、悬浮显示及厂商自启动开关仍受系统控制，不能静默开启，也不能保证所有机型的系统条目闪两次。
- 计划列表及新建/编辑计划页的提示卡增加关闭按钮，提供红色“不再提醒”和“本次关闭”。前者保存当前账号偏好，后者只隐藏当前页面；关闭提示不关闭真实提醒。设置中始终保留“通知与提醒”入口。
- 关闭、语音播放等图标按钮改成紧凑圆形，可见底色比图标略大，保留透明点击区域及原有交互反馈，减少正文挤占。
- 提醒关闭、训练退出、计划保存/删除、账号、AI对话及视频采集等确认弹窗共用统一布局：两个按钮同排、等宽等高、有边框，按操作用途保留强调底色。小屏、横屏或大字体下支持滚动，保留取消、保存和删除等原有操作含义。
- APK版本、App内显示及新训练记录版本同步为0.1.72（构建73），不改写历史记录。

## 安装与已有功能

通用release APK使用正式包名 `com.pianoforparkinson.piano_practice`，包含ARM64、ARMv7、x86_64。沿用本机内部测试开发签名，同包名同签名旧版可覆盖安装，保留本机数据；不要先卸载旧版。独立 `.validation` 包仍可并存。

保留手机号/账号密码登录、自动云同步、AI训练助手、舒缓节奏、左右手提示和三门舞蹈课程的插画及在线播放缓存。微信入口继续隐藏。沿用公开HTTPS账号API和AI网关地址，安装包不包含服务端AccessKey、AppSecret等配置，也不内置MP4/WebM。

自动化验证及构建通过不等于所有品牌真机验收。自启动和厂商后台活动无法统一自动核验，显示“需核实”；强行停止后仍需用户主动重新打开App恢复未来提醒。
