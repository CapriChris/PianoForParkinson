# 聚光灯新手引导

新用户完成原有语言与显示初始化后，自动进入主要页面引导。采用 68% 不透明度黑色遮罩、圆形镂空、呼吸边框及淡入动画。圆圈内允许操作原有控件，圈外阻止误触；说明面板提供下一步、上一步和跳过。系统要求减少动画时，停用呼吸和淡入动画。

训练配置中的模式切换、速度滑轨及两侧按键、整个预览、面部采集卡片和开始按钮，使用向外扩展 8 个逻辑像素的圆角矩形高亮，矩形区域内可操作。首页等小目标继续使用圆形。横屏“看提示符下落”的第一步使用纯说明面板和全屏遮罩，不显示聚光灯，文案仅介绍下落方向和长条时长。

## 引导内容

1. 首页、练习、计划、记录、设置：介绍各页用途，并随步骤展示对应页面。
2. 首次打开弹奏训练：选择曲目、两种模式、速度、播放预览、可选面部采集和开始训练。选曲抽屉等新页面会正常显示在引导上方。
3. 首次进入弹奏界面：介绍提示符长度、到键时按下、持续按住、尾端松开以及暂停和继续。讲解期间不启动训练或生成弹奏记录，完成或跳过后才显示开始确认。

说明面板可滚动，适应大字号与横屏。高亮位置在步骤切换、滚动定位和屏幕尺寸变化后重新计算。引导不自动申请摄像头权限，也不自动播放预览音乐，试听仍由用户主动点击。

## 进度与重看

进度按账号保存在原有设置中，分别使用 `spotlight_home_v1`、`spotlight_piano_v1`、`spotlight_play_v1`，完成或跳过后不再自动弹出。新用户完成初始化时设置 `spotlight_guides_enabled`；已有账号升级后不会突然弹出。

设置页提供“重新查看新手引导”，重置这三个引导标记并返回首页，之后进入弹奏配置与正式训练时可重新查看对应引导。此操作不重置入门教学完成记录、训练记录、登录状态或其他配置。

本功能在 `feat/waterfall-mp3-training` 分支继续开发，基于 PR #3，不引入额外运行依赖。
