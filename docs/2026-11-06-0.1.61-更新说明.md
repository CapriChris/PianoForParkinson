# 琴伴 0.1.61+62 更新说明

2026-11-06 · 本机账号功能验收版，尚未发布 GitHub Release。

- 新增强制登录：注册或登录后才能使用训练、计划、记录等功能；退出后返回登录页并移除原页面栈。
- 用户在 App 注册后，服务端自动创建对应患者档案，Web 患者列表可查看；不关联现有示例患者。
- 新增保持登录、安全凭证存储、自动续期、修改密码与一次性恢复码找回密码。
- 新增「设置 → 我的账号与同步」，展示账号、患者编号和同步状态，支持立即同步及退出。
- 本机数据按账号独立存储；旧版游客及联调记录保留原位置，不自动导入。
- 登录后自动开启同步，断网可练习，恢复网络后补传。增加有网络约束的 Android 后台任务，复用原上传队列。
- 独立后台同步不终结未完成训练；后台文件锁避免与前台同时切换账号数据。
- AI 记录访问与视频采集仍分别授权。

本轮包含本机配套后端代码及新增数据库迁移。必须先由队友部署后端，新 APK 才能在公网注册登录。未执行生产部署或真机安装。
