# 前台自动同步联调

Web 对照提交：WuChangqing1/PD-Rehab-Web cb75a00。

1. 使用测试账号登录，API 使用 https://ccqspace.site/pd-rehab/api。
2. 确认测试患者及本机档案归属，点击确认绑定，然后打开「前台自动同步」。
3. 保存训练后会触发同步。恢复前台时再次检查；有有效登录时，前台约每 30 秒重试。
4. 使用目标为两次的舞蹈计划复测：第一次完成后断网并保持前台，等待检查入队；
   第二次完成后恢复联网。Web「随访与报告 → 软件端记录 → 训练计划」
   应显示一条计划、当日 2/2，历史可见 1/2。重复同步不增加版本。

原始练习仍保存在 practice.db。旁路数据库升级至 v2，持久化待上传数据、
确认状态和计划版本。作用域包含服务器、工作人员账号、设备、档案和患者。
同一快照重试使用原记录 ID。永久拒绝的记录保留供排查，不占据重试队列；
超时、限流、网络及服务器暂时错误继续等待。权限拒绝或令牌过期停止上传，
待用户重新登录；App 重启也需要重新登录，密码和令牌不写数据库。

计划快照包含最近七日内适用日期的 daily_progress；次数按次，
分钟目标的完成量按毫秒、目标按分钟。修改生成新的 snapshot_revision。
最新快照未提供的旧日期可从历史快照核对。不要清除旁路数据库来处理重试，
否则可能丢失待上传数据与版本计数。

Web 患者与历史在云端页打开或回到前台时更新，历史只读；不复用上一账号的下载缓存。
此版不承诺 App 被关闭后仍能上传，也不实现两端共同编辑患者档案或计划。
