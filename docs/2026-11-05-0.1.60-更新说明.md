# 琴伴 0.1.60+61 更新说明

2026-11-05 · Android 内部测试版

## AI 训练助手

- 统一应用名称：中文「琴伴」，英文「Piano Companion」。
- 移除 App 中独立的「AI 康复问答」入口及页面，保留 AI 训练助手。
- 经用户授权后，助手可按问题查询相关训练记录。取消最多六条证据、最近两轮聊天的固定限制；保留单次请求大小和模型上下文容量保护。
- 新增本机历史会话、同一会话上下文和新对话；会话按本机档案隔离。撤回训练记录授权后，不再发送先前授权范围的训练上下文。
- 精简侧边栏：移除「历史对话」标题、关闭图标和说明文案；保留训练记录授权开关。支持点击左上角图标或从左向右滑动打开。
- 配套网关默认单个安装凭证每日额度提高至 100 次，供测试使用。全局与 IP 额度仍分别限制请求；线上最终额度取决于服务端环境变量。

## 钢琴训练退出

- 正式训练中点击左上角返回或系统返回，弹出「退出本次训练」，由用户选择「保存」或「不保存」。
- 「保存」按现有流程保留已完成部分并退出；保存失败时保留原有重试提示。
- 「不保存」删除本次已暂存的训练记录和计划关联，并恢复训练开始前的难度状态；删除失败时保留当前训练，允许重试。
- 关闭退出弹窗会留在暂停的训练页面，可继续练习。

## 安装与联调

- 版本 `0.1.60`，Android 构建号 `61`，包名 `com.pianoforparkinson.piano_practice`。
- 通用 Release APK 支持 ARM64、ARMv7 和 x86_64，四段舞蹈视频随包提供。
- 启用云端服务联调，API 地址为 `https://ccqspace.site/pd-rehab/api`；AI 网关为 `https://qin-ai-gateway-nbzaloppkk.cn-hangzhou.fcapp.run`，服务商显示为 DeepSeek。
- 本版包含仓库中已有的训练视频采集与同步功能。Web 配套接口及真机验收状态见对应交接文档。
- 沿用现有开发签名，可覆盖安装签名相同的主应用，保留本机数据。用于团队内部测试。

## 待验收事项

本机自动化测试不能代替真机和线上验收。安装后复测训练退出的两个选项、历史会话恢复、AI 服务和计划进度 `1/2 → 2/2` 的跨端同步。服务端网关代码需要单独部署，发布 APK 不会更新阿里云函数。
