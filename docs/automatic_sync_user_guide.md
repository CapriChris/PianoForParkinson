# 自动同步使用说明

1. 在「云端数据与 AI 服务」填写测试 Web 的 HTTPS API 地址（以 /api 结尾），用获授权的工作人员账号登录。
2. 核对患者并确认绑定。绑定成功后，默认开启前台自动同步。只有绑定之后开始的普通训练会自动上报；既有训练记录不会自动分配给当前患者。若旧计划确实属于该患者，可单独确认计划归属；不会补传之前的训练成绩。
3. 可以断网训练并在本机看成绩。返回前台或网络恢复时，系统检查待发送记录。App 被关闭后需重新打开并登录；这不是后台常驻服务。
4. 点「立即同步」可以手动检查上传和下载；正在同步时不会再起一个批次。服务器未启用增量时，云端历史只能在页面读取近期数据。
5. Web 中查看「随访与报告 → 软件端记录」。训练计划页按日期读取训练进度；缺数据会显示「进度未知」。
6. 录像仍默认关闭，需另行同意，且继续遵守 Wi-Fi 优先规则。只打开普通自动同步不会录制或上传视频。

同步失败请区分网络、登录失效、绑定撤销和服务器拒绝。退出后应用隐藏并清理该范围的云端缓存，待上传任务仍保留在原绑定范围。不要为解决失败而反复更换患者。测试 APK 与此前验证 APK 使用同一测试包名，不要卸载含测试历史的旧包来代替数据库迁移。
