# 琴伴 0.1.62+63 更新说明

2026-11-06 · 账号页面布局调整 · 本机安装包

- 登录和找回密码页面移除用户名格式提示；提示仅在注册页显示。
- 密码框获得焦点时才显示眼睛图标：密文对应闭眼，明文对应睁眼；图标在输入框右侧对齐并垂直居中。
- 注册与找回密码的确认密码框增加相同控件，与密码框独立控制。
- 「姓名或昵称」改为「昵称」；字符计数移入输入框右侧，实时按字符更新，仍限制最多 64 字符。
- 移除登录、注册及找回密码页底部说明。
- 移除注册页云端同步确认勾选板块。按产品要求，注册/登录即开启账号云端同步，不再需要额外勾选；AI 读取训练记录与视频采集仍分别授权。
- 保留原注册接口的 `sync_consent_version=account-sync-v1` 字段，不改变后端接口契约；此前交付的后端包仍可使用。

版本统一为 `0.1.62+63`。此前的 0.1.61 安装包和后端交接 ZIP 保留，不覆盖历史交付。

验证覆盖焦点与眼睛显隐、图标含义、确认密码独立切换、昵称计数及位置、移除勾选后的注册提交、三个页面的文案。构建和安装包校验见 [验证报告](../validation/release-0.1.62.md)。本轮未部署服务器或推送 GitHub。
