# 舞蹈跟练课程卡片布局（2026-11-13）

最初基于 App main `525f7da`、源码版本 `0.1.68+69` 实施。后续按用户发布要求合入队友 `8919055`（舒缓节奏与左右手提示），纳入 `0.1.70+71` 安装包；发布和最终验证见 [0.1.70 更新说明](2026-11-13-0.1.70-更新说明.md) 与 [构建报告](../validation/release-0.1.70.md)。下方“未构建或推送”属于各次源码修改当时的状态。

## 页面行为

- 舞蹈跟练入口成为独立课程列表：说明标题、引导语，以及三张左侧插画、右侧课程名/视频语言、末端圆形箭头的卡片。
- 复用旋律选择页的 `PracticeCard`、留白、米色背景、圆角和按压反馈，使用现有舞蹈插画，无新增在线图片依赖。
- 点击课程进入 `DancePreparationPage`，在那里查看所选课程、选择本次可选面部采集并开始练习。浏览课程不会启动视频播放器或申请采集；返回可重新选择课程。
- 用户补充更新：身心协调使用 `43-dance-brain-body`，律动与发声使用 `44-dance-move-shout`，原图来自 `assets/images/`，运行时使用优化 WebP；课程卡片副标题仅为中文/英文（英文界面 Chinese/English）。
- 准备页顶栏居中显示所选课程名，取消正文中重复的课程名和部分数。顶栏下依次显示对应课程插画、面部视频采集、温馨提示，底部保留开始练习，长内容可滚动。
- 按用户后续要求，舞蹈、短旋律、节奏准备页共用 `QinPreparationArtwork`：占满内容区宽度，高度按宽度/1.7计算，最小100dp，普通页面上限300dp、短横屏上限160dp。三门舞蹈不再按源图片比例分别确定显示尺寸；使用等比覆盖，不拉伸图片，舞蹈人物从上沿取景。
- 中英文均保留三门课程。视频资源、分段切换、缓存、播放时长、保存记录和计划同步逻辑保持现有实现；舞蹈历史卡片仅调整对应插画。
