## 现在如何使用

1. 安装新版 `PianoForParkinson-0.1.64-accounts-QA-arm64.apk`。
2. 普通使用者在 App 注册，确认训练记录/计划同步，保存一次性恢复码。请勿把 Web 工作人员账号当作普通患者登录入口。
3. 完成训练后本机先保存成绩，联网时自动同步；在 Web 选择相应患者，查看“随访与报告 → 软件端记录”和计划进度。
4. 独立同意训练录像后，沿用录像采集与上传流程；Web 对应训练详情可查看、播放、下载仍在保留期内的 MP4，并按权限复核和查看结果。
5. App 设置中的“我的账号与同步”可以查看身份/同步状态、手动重试、改密和退出。改密或恢复码重置后重新登录。

App 默认 API：`https://ccqspace.site/pd-rehab/api`。预发布构建覆盖参数使用当前队友架构的 `PD_API_BASE`；11 月 6 日旧分支文档中的 `PD_ACCOUNT_API_BASE` 属于历史实现，不适用于本次安装包。
