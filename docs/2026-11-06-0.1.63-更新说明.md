# 琴伴 0.1.63+64 更新说明

2026-11-06 · 图标、账号页插画与密码提示

- 使用 `assets/icon/icon.png` 更新 Android 启动图标，生成五档密度和自适应图标；保留原图内容。通知仍使用适配通知栏的单色资源。
- 登录、注册和重置密码页共用 `assets/images/42-auth-shared-header.png` 顶部插画。插画在文字下层，不拦截触摸；保留品牌名并移除原钢琴符号。
- 顶部根据文字自然高度扩展，小屏横屏和大字号可滚动访问表单。
- 「找回密码」页标题改为「重置密码」，原「忘记密码」入口保留。
- 注册、重置和修改密码的新密码规则统一为 8–16 位；空值提示先输入密码，长度不符时提示「密码须为8-16位」。
- 注册和重置页的密码框下方常驻要求提示；确认密码框不重复显示要求。确认密码为空时先提示重新输入，输入后再核对一致性。
- 后端同步限制新设密码长度，旧账号仍可使用原有密码登录。

本轮后端有密码规则更新，提供新的 `web-mobile-accounts-0.1.63-handoff.zip`。已有账号功能部署只需合并代码并重启；从旧版首次部署账号功能仍需执行原 `n0c2d4e6f8a0` 数据库迁移，本轮没有新增迁移。

版本统一为 `0.1.63+64`，交付标签为 `v0.1.63`。配套 Web 变更见 [草稿合并请求 #1](https://github.com/WuChangqing1/PD-Rehab-Web/pull/1)，公网部署与真机验收由团队另行完成。
