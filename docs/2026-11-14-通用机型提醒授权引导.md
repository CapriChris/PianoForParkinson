日期：2026-11-14。本机 `0.1.71+72` 本次覆盖构建采用下述布局，替代此前自动串行打开厂商页面的流程。未推送 GitHub。

后续同日公开交付为 [0.1.72](2026-11-14-0.1.72-更新说明.md)，保留下述授权流程并统一紧凑圆形图标与双按钮弹窗。0.1.71未推送为前期本机构建状态；最新验证见 [0.1.72构建报告](../validation/release-0.1.72.md)。

## 用户流程

计划列表、新建/编辑计划页的“提醒设置”进入同一页面。设置页另保留“通知与提醒”入口，即使隐藏提示卡片也能再次配置。通知和准时提醒已开启时，卡片显示“通知与准时提醒已开启。请进入提醒设置，检查自启动和后台活动。”

1. 进入页面自动检查通知、训练计划通知类别和“闹钟和提醒”权限，缺少时发起系统申请；已开启则跳过。系统弹窗仍由用户选择。拒绝后不因返回前台而反复申请，用户可以重试或选择普通提醒继续。
2. 自启动与允许后台活动分别提供“去开启”，仅点击对应按钮才跳转。返回后复查系统可读取的权限，不自动打开另一页。
3. 通知显示提供独立“去开启”，打开本应用通知设置，并传入训练计划通知类别供系统定位。熄屏、锁屏和悬浮显示由手机系统控制，App 无法统一静默开启，也不会覆盖用户已修改的通知类别设置。
4. 自启动没有统一查询接口；访问页面后显示“需核实”，不能据此宣称已经开启。电池优化豁免通过公开接口检测，它也不等同于厂商全部后台限制均已解除。
5. 返回计划页后重新调度当前账号未来的提醒；隐藏提示不关闭计划提醒。

## 提示卡片关闭

计划列表、新建/编辑计划页的提示卡右上角均有关闭按钮。点击显示“请确保已开启所需权限后再选择‘不再提醒’”（界面使用中文双引号），提供红色“不再提醒”和“本次关闭”。

- “不再提醒”保存当前账号的偏好，两个入口都隐藏；保存失败时提示重试。
- “本次关闭”只隐藏当前页面实例，重新进入页面可再次显示。
- 返回键或点击弹窗外不改变偏好。小屏、大字体下弹窗可滚动访问按钮。

## 机型路由及高亮

| 系统族 | 自启动入口 | 后台设置 |
|---|---|---|
| vivo / iQOO | 权限管理及旧版 i 管家入口 | 应用信息，说明电量 → 后台耗电管理 |
| 小米 / Redmi / POCO | MIUI/HyperOS 自启动管理 | 应用信息，说明应用省电策略 |
| 华为 / 荣耀 | 各自系统管家的应用启动管理，兼容旧入口 | 应用信息/电池设置 |
| OPPO / realme / OnePlus | ColorOS/OPlus 新旧启动管理入口 | 应用信息/电池设置 |
| 魅族 | 系统应用权限管理 action | 应用信息/电池设置 |
| 三星 | 不展示不存在的统一自启动权限 | 应用信息，说明休眠应用限制 |
| Google / AOSP / 摩托罗拉 / 索尼 / Nokia/HMD | 标准 Android，不强制自启动 | 应用信息 |
| 其他 | 应用信息页 | 应用信息/标准电池管理回退 |

跳转附带“琴伴”的包名，以及 Settings 可识别的定位、高亮参数。通知设置使用 Android 官方 `EXTRA_CHANNEL_ID` 定位通知类别；厂商自启动列表可忽略这些参数。未找到或受保护的厂商页面回退应用信息，再尝试标准设置，不绕过受保护页面。

**自启动条目的自动定位和闪烁属于接收方系统页面行为，没有统一公开接口保证各品牌支持，也不能由 App 指定恰好闪两次。** 原生接口仅返回已请求高亮、未验证效果，不使用 App 内闪烁冒充系统条目。当前未连接各品牌真机，不能将路由实现或替身测试表述为实机高亮验收。

不新增悬浮窗、无障碍、Root、ADB 或全量应用查询权限，不添加保活服务。强行停止后的系统限制仍需用户重新打开 App 才能恢复未来提醒。

## 实现与验证

- `lib/features/reminder_setup_page.dart`：布局、独立开启按钮、品牌说明、真实状态。
- `lib/platform/reminder_setup.dart`：标准授权与生命周期复查；厂商页只接受显式按钮操作。
- `lib/features/plans_page.dart`：关闭弹窗、当前账号提示偏好及重新调度。
- `lib/app/piano_app.dart`：始终可用的设置入口。
- `ReminderSettingsBridge.kt`：品牌路由、包名和高亮参数、标准状态查询与回退。
- `android/app/src/main/res/raw/keep.xml`：保留通知图标，修复 release 资源缩减导致初始化失败。

本轮按要求仅跑相关测试：56 项通过，覆盖授权/拒绝/重试、独立跳转及返回复查、提示临时与永久关闭、弹窗取消、小屏中英文大字体、计划编辑与提醒调度。静态分析无问题。日志为 `build/reminder-layout-20261114-tests.log`、`build/reminder-layout-20261114-analyze.log`。最终 APK 记录见 [构建与验证](../validation/release-0.1.71.md)。本次包含原生代码，需要完整重新安装，不能仅热重载。
