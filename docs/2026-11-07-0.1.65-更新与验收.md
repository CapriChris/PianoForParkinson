## 现在需要做什么

1. 安装本机整合版 0.1.65+66，确认使用的是「琴伴」正式包，而非队友的 `.validation` QA 包。已有同签名正式包可直接覆盖安装，不卸载、不清空数据。
2. 在 App 注册一个专用于联调的普通账号并保存一次性恢复码；不要拿 Web 管理员账号当患者账号登录。Web 管理员找到新建的对应患者，核对昵称和患者编号。
3. 建立每日目标 2 次的测试计划。第一次完成后，Web 应有训练记录且进度为 1/2；第二次完成后应为 2/2。手动重复同步、退出页面再进入和重启，不应多出重复记录或回退进度。
4. 已登录状态下断网训练，确认本机成绩/进度保存；恢复联网，观察自动补传一次。验证切到后台再回前台、杀进程重开和手机重启后的身份及数据恢复。
5. 注册/登录第二个测试账号，核对历史、计划、AI 会话和录像与第一个账号隔离；切回第一个账号，原记录仍在。
6. 验证恢复码重置、改密、退出、重新登录；旧凭证应失效，退出后不能返回训练页面。
7. 录像仍按独立授权流程测试摄像头、加密保存、上传及 Web 播放下载；无需测试 AI 康复问答。记录手机型号、Android 版本、App 版本、患者编号、操作时间、App 同步状态、Web 结果和截图，便于定位。

手机摄像头、Keystore 跨重启、真实 WorkManager 调度、厂商省电与双 Android 引擎竞争仍待真机验收。自动化通过不能替代以上设备检查。

## 需要队友知道的差异

- 队友上线记录中的“注册前确认自动同步”描述的是其 0.1.64 QA 包；本机 0.1.65 按用户既定需求去掉该额外弹窗。
- 当前 App 新密码校验为 8–16 位；同步到的 Web 后端接口允许 8–64 字符且 UTF-8 不超过 72 字节，接口比 App 宽。若需要服务端也严格执行 8–16 位，应另改注册/新密码接口，同时保留旧账号登录兼容。
- `docs/account_registration_deployment_handoff.md` 中旧版本、旧构建参数与“尚未部署”是历史描述；当前部署状态以 2026-11-07 上线记录为准。
