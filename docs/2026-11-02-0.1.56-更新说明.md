# 琴伴 0.1.56+57 更新说明

日期：2026-11-02（北京时间）。平台：Android，内部演示/测试版本。

## 舞蹈跟练

中文课程使用新平衡舞步六式第一、第二、第三部分；英文保留Fandango。视频作为离线资源随APK分发，界面仅记录实际观察到的播放时长，不推断动作质量。

练习入口与准备页使用对应插画。播放页可以切换三部分并保留本次位置；播放/暂停、进度、竖向音量、0.75/1.0/1.25倍速和全屏都在视频内操作。拖动期间暂停，结束后恢复拖动前状态；全屏有返回按钮。单段结束提示下一部分，退出前明确提示不会保存。

结束并保存进入插画完成页，展示保存状态、记录时间、到达结尾的部分数及分段播放时长；失败可重试同一会话。底部为再练一次/返回首页，重新练习创建新会话。历史详情直接读取已保存记录，不再次写入。

## 训练计划

底栏新增计划。支持舞蹈、钢琴曲目及七项钢琴练习子项目，次数目标1～1000；目标控件支持加减1及手动输入。开始/结束日期、仅一次/每天/工作日/周末/自定义星期、通知开关和滚轮时间均可编辑。新计划提醒时间默认取打开编辑页时的设备时间。

进度从当日已保存且符合项目的记录自动计算，同一计划内不重复计数；每个计划独立衡量目标。取消手动关联和跳过入口。卡片点击编辑，右侧开关启停，长按进入批量删除，工具栏固定；删除计划不删除训练记录。编辑有未保存更改时提供保存或放弃。

计划以未结束/已结束分组，各自按开始日期及提醒时间升序。仅一次计划在其开始日之后结束，重复计划在指定结束日之后结束；无结束日的重复计划保持有效。到期自动保存为禁用状态，开关关闭且不能直接开启，可编辑日期后再启用。手动禁用但未到期的计划仍在未结束组。

计划页使用插画背景，卡片按训练项目选择插画并加文字遮罩。标题下保留简洁文案，底部居中半透明加号用于新建。没有计划时，在内容区域中央显示无插画的卡片：“暂无计划 / 点击下方按钮创建你的计划”。

## Android通知

使用系统时间与时区。分别检查普通通知权限、训练通知渠道及“闹钟和提醒”精确定时权限；保存计划不会自动跳转特殊权限页，只有点击设置入口才打开。获准时使用允许待机的精确定时，否则会提示可能延迟。修复已到点但未投递的提醒在刷新时被误取消的问题。

打开/恢复应用以及相关记录保存时更新未来30天的系统安排，通知点击打开计划页。系统已登记的提醒不依赖应用持续在前台，但强行停止、关闭权限、勿扰及厂商省电策略会影响送达；尚未完成各品牌真机矩阵，不承诺所有系统条件下准点。

## 记录与通用界面

最近练习合并七项练习、钢琴曲目及舞蹈，按时间分页并验证原始记录完整性。记录分类为全部、钢琴练习、钢琴曲目、舞蹈训练；窄屏简写，背景和触控区域等宽。练习分类也统一均分可用宽度。跨页筛选会继续查找后续匹配记录，空状态和读取失败可重试。

首页、练习、记录、设置及计划使用各自插画；保留文字柔化、高对比度和中英文布局。按钮有轻微按压动画，动作在动画结束后执行；嵌套开关不触发整卡动画。原90%字号映射为新的100%，琴键及谱面保留其独立缩放逻辑。七项钢琴练习的开始、重练及首页按钮补齐图标。课程来源从练习页面移至关于页。

## 数据、模型与构建

SQLite升级到schema4，新增舞蹈和计划表，保留旧迁移校验和及备份保护；原有训练计分不重算。CausalNet目前仅有桌面检查脚本与合成输入结果，权重来源和训练配置仍需团队确认；本版没有摄像头采集、模型端侧运行或AI指导功能。

本仓库不提交视频二进制、APK、数据库和密钥。Release通用APK包含完整离线视频，可用tools/prepare_dance_asset.py从APK恢复构建所需视频并校验SHA-256。主包与旧预览版升级包行为一致，仅包名不同，均使用现有开发签名；覆盖安装时务必匹配原包名。

构建结果及测试限制见[发布验证](../validation/release-0.1.56.md)。本版没有完成全套测试或全部真机验收，以GitHub Pre-release分发。
