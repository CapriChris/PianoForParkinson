# 琴伴 0.1.59+60 更新说明

2026-11-03 · Android 本地测试版

## 布局与交互

- 练习和记录页的分类按钮等宽。能容纳全部完整名称时显示全称，空间不足时使用简称。
- 钢琴曲目页按卡片可用宽度和字号选择双列或单列。常见手机宽度下优先展示双列，高对比度下保留单列。
- 计划批量操作栏随宽度安排控件，自定义重复的七个星期按钮等分可用空间。计划目标根据加减按钮、数字和单位需要的宽度决定是否换行，空间足够时与其他字段同排对齐。
- 琴键粒子在相邻琴键上方绘制，避免右侧粒子被遮挡。

## 数据与性能

- 计划列表和提醒调度批量读取练习进度，减少重复数据库查询。
- 复用曲目试听与正式弹奏的键位计算，以及练习项目和记录校验的公共定义。

## Android 安装包

本地提供 `qinban-0.1.59-android-universal.apk`，包名为 `com.pianoforparkinson.piano_practice`，沿用开发签名。支持 ARM64、ARMv7 和 x86_64，随包包含全部四段舞蹈视频。本次仅构建主应用通用包。[构建与验证](../validation/release-0.1.59.md)
