## 实现边界

- 普通训练和 App 发起的计划是双向同步体系中的上传数据；Web 原生评估、历史和计划为 Flutter 增量只读。Web 不支持让 Flutter 修改工作人员、临床档案或覆盖 Web 原生计划，本轮没有添加编辑入口。
- 普通同步仅在前台，Android 网络恢复事件与周期检查并用；业务记录保存不等待网络。未核实的旧练习不会自动上报；旧计划需要人工确认归属才同步。历史版本侧库中的旧队列保留，未跨到新绑定范围，也未把没有可靠归属的旧待处理记录自动重放。
- 录像仍由原授权、Keystore 加密、Wi-Fi 策略、分块和独立调度处理。此次真实 HTTPS 测试未录制或提交患者影像；录像/真实 CausalNet 的先前独立预发布证据见 Web 录像验收报告。
- 当前 Web 增量索引用于 SQLite；MySQL、整个授权患者目录的增量和 Web/Flutter 同一临床计划协作编辑见 API 待办。生产发布需单独批准。
