# 琴伴 0.1.66+67 更新说明

日期：2026-11-07。Android 内部测试版，在 0.1.65+66 的双端账号整合基础上构建。发布标签 `v0.1.66`，包名与开发签名沿用现有正式应用，可覆盖相同包名及签名的旧版安装。

- 设置页“我的账号与同步”入口移至“面部采集与上传”正上方；移除视频列表中的“连接训练档案”按钮。
- 首次使用的三个引导页移除右上角退出账号入口。
- “我的账号”页的立即同步、修改密码、退出登录、返回按钮，以及修改密码和退出确认弹窗，使用统一按压反馈；沿用原有账号处理逻辑。
- 临时生命周期失活不再直接判定为后台；通知允许降音量时保持训练时钟和播放。真正进入后台、窗口被接管、音频焦点丢失或输出路由变化时暂停；恢复焦点不自动继续。
- 钢琴曲目手动继续前显示三拍视觉准备，准备期间再次中断会取消恢复。触控被系统取消时暂停。
- 舞蹈使用统一音频中断策略，缓冲/播放故障后暂停，回到前台或声音恢复后等待用户手动继续；迟到的播放请求不能绕过暂停。
- 通知结束后恢复舞蹈原先设置的音量。录像随真正中断暂停，普通临时失活不会提前结束录像。
- 延续已上线的普通账号注册登录与自动同步，API 默认 `https://ccqspace.site/pd-rehab/api`，AI 网关继续使用现有阿里云地址。本轮不修改后端或执行生产部署。

Android 各厂商悬浮窗上报方式存在差异：非抢焦点通知按不中断处理，真正夺取输入焦点的窗口按中断处理。Vivo 实际通知、来电、通知栏、耳机切换和锁屏仍需真机验收。
