# 琴伴 0.1.71（构建 72）更新说明

日期：2026-11-14。本机通用 release APK，基于0.1.70的后续提醒功能修复；本轮不推送仓库或创建 GitHub Release。

后续公开交付为 [0.1.72](2026-11-14-0.1.72-更新说明.md)，包含这里的修复和后续图标/弹窗优化。本文“本轮不推送”等表述记录0.1.71本机构建阶段，不代表0.1.72发布状态。

- 保留通知图标 `piano_icon`，修复 release 资源缩减导致通知插件初始化失败、计划页显示“无法读取提醒权限”的问题。
- 统一“提醒设置”入口，依次检查通知、训练提醒通知类别和准时提醒权限；已允许的系统权限自动跳过。计划页提示同步改为进入提醒设置检查自启动和后台活动。
- 提供常见 Android 品牌的自启动/后台管理入口，找不到或无法访问时回退标准系统页面；原生 Android 按标准权限流程处理。不是仅适配 vivo，也不代表所有品牌 ROM 已真机验证。
- 本次同版本覆盖更新：自动申请通知及准时提醒，自启动、允许后台活动分别提供“去开启”，从设置返回只复查、不自动打开下一厂商页面。
- 跳转传入本应用包名和定位/高亮提示；通知设置可请求定位训练计划通知类别。厂商自启动列表是否支持定位或闪烁由系统决定，无法统一保证闪两次。无法核验的厂商开关显示“需核实”，不因打开过页面而判定已授权。
- 计划列表和新建/编辑页的提示卡增加关闭按钮；弹窗提供红色“不再提醒”（保存当前账号偏好）和“本次关闭”（仅当前页面）。设置中保留“通知与提醒”入口，关闭提示不影响实际提醒。
- 移除用户指定的三段提醒设置说明，中英文同步；保留必要状态与按钮。
- 统一 APK、App 内展示及新训练记录的版本信息为0.1.71（构建72），修正此前源码中仍保留的旧版本常量；不改写历史记录。
- 保留已有舞蹈插画、舒缓节奏、左右手提示、手机号登录、自动同步、AI 训练助手和远程视频播放缓存。

包名保持 `com.pianoforparkinson.piano_practice`。同包名、同签名的旧版可覆盖安装；独立 `.validation` 包仍可并存。安装时不要先卸载旧版，以免删除本机数据。

真实手机可能仍需用户允许通知、自启动和后台运行。熄屏、锁屏、悬浮通知由系统设置控制，提供独立开启入口，不能统一自动开启。App 不替用户静默授权，不申请悬浮窗或无障碍权限，不绕过 Android 强行停止机制。

安装包信息及验证见 [构建报告](../validation/release-0.1.71.md)，机型范围和授权细节见 [通用机型提醒授权引导](2026-11-14-通用机型提醒授权引导.md)。
