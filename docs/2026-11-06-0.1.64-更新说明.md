# 琴伴 0.1.64+65 更新说明

2026-11-06 · 账号页面按钮交互反馈 · 本机验收版

- 登录、注册、重置密码的主按钮及页面切换链接复用 App 统一按压效果，按下轻微缩小、下沉，松开恢复；取消按压不会触发提交。
- 提交期间显示加载图标和「登录中…」「注册中…」「重置中…」，禁用提交及切换按钮，防止重复请求；失败后保留表单并恢复重试。
- 密码和确认密码的眼睛按钮加入相同按压反馈，保持输入焦点、选择范围和独立显隐控制。
- 注册及重置后的恢复码弹窗按钮使用统一反馈，复制成功显示「恢复码已复制」。
- 遵从系统减少动画设置。

本次只修改 App 界面交互，沿用 0.1.63 后端协议和交接包。版本统一为 `0.1.64+65`，本轮尚未推送 GitHub 或部署服务器。
