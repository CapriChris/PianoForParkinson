## 已有实现的边界
1. Flutter 原有 piano/dance/离线流程保持在本地；面部分析仅通过 Web 真模型接口，缺模型配置则不可用。
2. 当前数据联通**不是全面自动双向编辑**：Flutter 原始记录→Web；Web 患者/员工/原生训练历史→Flutter 是只读快照。同步时不混合不同指标算法的结果。
3. AI 问答仅提供服务器可配置模型 API（并非已部署的专家系统）。无提供商配置则返回 503，尚未实现可信知识库 RAG、患者记录解读。
4. 无生产环境数据迁移/重启/上线；无真实患者视频传输。
