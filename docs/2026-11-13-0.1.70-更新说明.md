# 琴伴 0.1.70（构建 71）更新说明

日期：2026-11-13。基于队友最新 main `8919055` 合入本机舞蹈界面优化，保留 0.1.69 的舒缓节奏和左右手提示。

## 本次更新

- 舞蹈课程列表参照旋律选择页，使用左侧插画、课程名称、中文/英文标签和箭头卡片；点击后进入独立准备页。
- 身心协调、律动与发声使用各自新增插画；新平衡舞步六式保留对应插画。准备页顶栏显示所选课程名称，下方依次为插画、面部视频采集及温馨提示，底部为开始练习。
- 舞蹈、短旋律及节奏准备页复用相同响应式插画尺寸规则，横竖屏保持一致，等比裁剪、不拉伸。
- 完成页和记录页舞蹈卡片按课程显示对应插画，与课程列表、准备页共用映射；缺少课程信息的旧记录保留通用兜底显示。
- 新增插画保留原图，运行时使用优化 WebP。本次不改变舞蹈视频、训练计时、成绩、计划进度或同步契约。

## 安装与已有功能

发布通用 release APK，使用正式包名 `com.pianoforparkinson.piano_practice`，支持 ARM64、ARMv7、x86_64。沿用本机内部测试开发签名；同包名、同签名旧版可覆盖安装。独立 `.validation` 包仍可并存，两个包的数据目录独立。

保留舒缓节奏、左右手提示、账号密码/手机号登录、自动同步和 AI 训练助手；微信登录入口继续隐藏。账号服务地址为 `https://ccqspace.site/pd-rehab/api`，AI 网关沿用现有阿里云地址。三门课程十段视频在线播放并缓存，未缓存内容需要网络，APK 不内置 MP4/WebM。

构建与自动化结果、APK 摘要及真机待验事项见 [构建与验证](../validation/release-0.1.70.md)。详细舞蹈界面过程记录见 [课程卡片布局](2026-11-13-舞蹈课程卡片布局.md)。
