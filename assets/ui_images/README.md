# 界面素材的应用内版本

本目录中的 WebP 由 `../images/` 中用户提供的同名 PNG 缩放并转换而来，最长边不超过 900 像素；原有资源质量参数为82，新增36～39号资源为88。原始 PNG 保留在 `images/`，Flutter 打包时使用本目录，避免将大尺寸原图全部放入安装包。素材仅用于装饰；曲名、指标、乐谱与按钮由应用实际数据和控件绘制。

2026-11-13：新增 `43-dance-brain-body.webp`（身心协调）和 `44-dance-move-shout.webp`（律动与发声），由对应用户 PNG 转为 900×900、质量88的 WebP。课程卡片与练习准备页共用各自插画，原图不修改。
