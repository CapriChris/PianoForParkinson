# 琴伴视觉组件

滚动曲谱使用 `ScrollingScoreCache` 保留文字排版、谱号／谱线／演奏线图片和音符矩形。缓存跟随组件生命周期，换曲、旋转尺寸或更换高对比主题时刷新，页面销毁时释放。每帧读取一次当前音和位置，只平移与绘制可见音符；避免帧内创建字体排版资源。

钢琴曲目中的 KeyMark 按音级取形，避免含低音或省略音级时发生错位。各八度的 1–7 沿用三角、圆、方、菱形、星、六边形、十字；数字的上／下圆点区分八度。正式琴键和试听共用 PianoPiece.keyShape，原训练默认的编号图形保持。

`qin_theme.dart` 是颜色与主题的单一来源；页面和绘制器使用 `context.qin` 或 `Theme.of(context)` 获取颜色。默认暖灰白、白色内容面与深绿主色；高对比使用完整的黑白令牌，不依赖自动派生配色。

`qin_components.dart` 提供页面与展示组件：

| 组件 | 用途 |
| --- | --- |
| QinPageList | 普通页面安全区、响应式边距与正文限宽；不用于正式训练键盘 |
| QinActionPage／QinActionRow | 说明与结果页固定主要操作；宽度／字号决定操作列数，极矮窗口可整页滚动 |
| QinPanel | 白色／浅绿内容面，16 dp 圆角与装饰分隔线 |
| QinSectionTitle | 区域标题和辅助说明 |
| QinStatus | 普通、完成、提醒、错误状态，图标与文字共同表达 |
| QinEntryCard | 整行可点击的练习、教学、曲目和历史入口 |
| QinMetrics | 结果及校验摘要；根据宽度与字号切换列数；两列下奇数末项通栏 |
| QinStepProgress | 首次引导、教学和规则试玩的步骤展示 |
| QinEmptyState | 空内容和可恢复异常的说明及操作 |
| QinNavigationBar | 首页／练习／记录；文字完整跟随系统比例，矮横屏图标与标签同行，布局随内容增高 |

基础交互至少 60×60 dp。图标常规为 24～28 dp，但不等于其触控面积。正文／操作说明 20 sp，辅助说明 18 sp，按钮 20 sp，普通标题 28 sp，横屏标题可用 24 sp。大字号允许组件增高，不能使用缩放或固定文字比例掩盖溢出。

琴键、时值、响应倒计时和两种节拍组件保留在 `features` 中，共享同一主题；这些组件不管理训练时钟、判分和会话数据。目标键使用浅底和 3 dp 边界，实际按下使用深底浅字，禁用／锁定使用中性灰。编号、位置与图形语义保留。普通补充图形由 KeyMark 绘制统一尺寸；G3 的 ShapeMark 保持不变。正式与双区预览共用 practiceKeyHeight，六键中央仍为 24 dp 间隔。

首页、T3 横屏和 M2 是代表布局：

- 首页：简短问候 → 推荐主操作 → 再练上次 → 旋律建议 → 完整目录／教学；未保存提示优先。
- T3 横屏：紧凑顶栏 → 语音说明 → 节拍器速度独立行 → 四拍独立行／整段进度 → 示范与翻页操作 → 固定琴键。第一页面向节拍观察，无琴键但预留同等下部空间；三页操作行位置一致，第二／三页固定键盘，上方说明局部滚动。极矮窗口提供整页滚动退路。
- M2：紧凑顶栏 → 固定位置的阶段／组项／倒计时 → 左右两区各三键，中间间隔 24 dp；入口与首次双触点检查沿用已有规则。

不为实时刺激添加颜色缓动、缩放、额外周期计时器或强制出帧。普通页面的折叠过渡遵从系统／应用减少动画设置。语音播放图标读取原生 TTS 事件，通过 generation 与 speech epoch 排除迟到事件，不轮询播放状态。

0.1.20 教学采用固定翻页占位，第一页上一页置灰，末页完成教学沿用下一页位置。普通键盘 6／7 的补充图形为六边形／十字形；G3 刺激保持。G1／G2 单项记录提示统一显示刚完成项号，具体见 [修订](../../../设计修订/2026-10-20-教学翻页位置与单项记录反馈.md)。

0.1.21 所有训练项号使用 TaskEngine.currentItemNumber 的只读阶段投影及统一 itemCounter。记录间隔显示刚完成项，节奏响应阶段跟随可见拍点。收尾不等于记录完成；单项／组末统一 recordedItem，保留组末继续操作。见 [修复与回归](../../../设计修订/2026-10-20-全模式记录反馈与项号时机修复.md)。

0.1.22 教学与正式节拍器共用 MetronomePendulum，摆杆和圆点围绕固定支点刚性旋转，保持杆长及圆点位置。继续使用各自既有时钟，不新增周期动画。G1 收尾阶段隐藏说明文字并保留标题高度与当前组／项，实际完成后再显示单一记录反馈。见 [修订](../../../设计修订/2026-10-20-旋律记忆收尾文字与节拍器摆杆修复.md)。

0.1.23 按用户补充要求覆盖上一版 G1 收尾占位：tail 阶段整个提示和组／项隐藏，外层空卡片也不绘制；正式记录后才显示共用 recordedItem。琴键区域仍固定。见 [修订](../../../设计修订/2026-10-20-旋律记忆收尾反馈区隐藏.md)。

0.1.24 为消除收尾空白，G1 收齐输入后立即显示共用 recordedItem，tail／release 到正式记录反馈持续使用同一面板与当前编号；不改变收尾观察或计分。覆盖 0.1.23 的收尾隐藏处理。见 [修订](../../../设计修订/2026-10-20-旋律记忆即时连续反馈.md)。

0.1.27 独立钢琴曲目先在准备页选择速度并试听，演奏页请求横屏全屏。左侧固定返回与暂停图标，上方长条曲谱、下方固定五键；不显示标题、速度或独立时值条。长条位置由 ScrollingPiecePlayer 的单调时钟直接绘制，长度按乐谱时值成比例，编号作为音高图形标记。见 [修订](../../../设计修订/2026-10-22-横屏滚动长条曲谱.md)。

0.1.28 准备页改用至少 60 dp 高的五档速度滑块，中文单位为拍/分钟，移除冗余说明。试听后出现只读滚动曲谱与五键自动演奏预览，音频、长条与亮键共用 ScrollingPiecePlayer 时间轴。停止和后台中断冻结，调速在松手后生效。见 [修订](../../../设计修订/2026-10-22-速度滑块与试听演奏预览.md)。

0.1.29 速度读数位于滑块左侧，试听先预备四拍，目录只显示曲名与作者。滚动长条使用高音谱表的正确 C4–G4 音高位置和中音 C 下加线，谱号限制在固定区域。正式曲目结束打开独立完成页，明确显示保存中／已保存／重试状态；记录页可回看与重弹。见 [修订](../../../设计修订/2026-10-22-曲目完成记录与五线谱.md)。

0.1.30 高音谱号按自然字体度量与布局框适配，取消强制行高与非等比拉伸并预留墨迹外延空间；演奏线顶部留出 12 dp。长条高度改为谱线间距 1.2 倍、18–34 dp，保持音高中心与横向时值。正式页与试听预览共用绘制器。本轮未运行测试与设备验收。

0.1.31 按用户最新要求去掉中音 C 的加线，正式页与试听预览同步；覆盖 0.1.29 的中音 C 加线显示规则，其他曲谱几何与时值保持。

0.1.32 钢琴曲目按独立音域配置显示五至八键，数字的上下点表示八度，长条与琴键使用同一标签和音高映射。支持三拍子、弱起小节线与延音；休止显示短横标记，试听不发声、演奏琴键锁定。六键曲目保持单排等距布局，原双区模式的分组间距仍使用原默认行为。

0.1.33 按用户要求将休止符标记由短横改为数字 0，覆盖上一版的短横显示规则，正式弹奏与试听预览同步。
